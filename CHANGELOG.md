# Changelog

All notable changes to this project will be documented in this file.

The format is inspired by [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2024-09-17

### Added
- Packaging scripts and CI jobs for Rust crates, npm (WASM), Unity, and Godot bundles.
- Optional SIMD scoring feature flag and deterministic Criterion baselines.
- End-to-end fuzz smoke runs and benchmark comparison tooling.
- Installation guides covering Rust, Python, Web, Unity, and Godot consumers with version support matrix.

### Changed
- Bumped crate, npm, and Python package versions to 0.2.0 for the first SemVer-stable API commitment.

## [0.1.0] - 2024-05-01

### Added
- Initial universal word engine prototype with Move generation, AI hints, persistence, and bindings (Rust, Python, WASM).
- Docusaurus documentation site and interactive playground.
